k1r0v написал:
DLL-инъекция vs внешний — что безопаснее под нынешний Faceit AC?

Под Faceit однозначно внешний, если хочешь долго продержаться. Инъекция сейчас слишком рискованна — Faceit AC работает на уровне ядра и мониторит memory access к процессу.

Юзаю внешний ESP уже 4 месяца на Faceit 10 — ни одного бана. Аимбот не использую принципиально — слишком заметно для AC pattern analysis.

// Пример безопасного ReadProcessMemory через driver
BOOL ReadMem(HANDLE hProc, uintptr_t addr, void* buf, size_t sz) {
    SIZE_T read;
    return ReadProcessMemory(hProc, (LPCVOID)addr, buf, sz, &read);
}

По plush.cc private не скажу — не юзал лично, но на форуме отзывы в основном позитивные. Попробуй спросить в их закрытом разделе.
